STEP 1: WINDOWS CONTROLLER FIX

Why:
Windows has its own controller navigation. When a controller is connected,
Windows uses it to move around Start, Quick Settings and notifications at
the same time FullTilt moves your mouse. This fix turns Windows' version
off, so only FullTilt responds.

Turn the fix on:
Double-click Disable_Windows_Controller_UI_Navigation.reg
and choose Yes when Windows asks.

Undo it any time:
Double-click Restore_Windows_Default_Controller_Navigation.reg
and choose Yes. Windows goes back to its default behavior.

Good to know:
- You can open FullTilt and try it before doing this. The fix just makes
  the experience smoother.
- It changes one Windows setting and nothing else.
- FullTilt never changes this setting by itself.
