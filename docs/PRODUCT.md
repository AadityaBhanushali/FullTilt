## Platform

windows

Native Windows 11 x64 desktop application using C#/.NET 10, WPF and Windows XInput. This is a Windows-specific platform; Impeccable's web/iOS/Android/adaptive categories do not describe it.

## Users

FullTilt serves people controlling a PC from a couch, people doing everyday desktop work, and people using a controller for accessibility needs. All three are primary use cases; no priority between them has been established.

## Product Purpose

Let people use an XInput controller to move the pointer, scroll, operate desktop applications and invoke keyboard actions. Success means they can configure and use those actions reliably in their own Windows workflow, retaining control over assignments, movement and profiles.

## Positioning

FullTilt combines controller-to-mouse movement, configurable held keyboard actions and hold-and-flick pie menus with per-menu D-pad actions in a portable Windows application. It requires no installer, account, backend, telemetry, administrator access or service. These are product capabilities, not a claim of exclusivity or superiority over other tools.

## Operating Context

People use FullTilt with an XInput controller and their existing Windows desktop applications, from a couch or during everyday work, including accessibility-related use. Application focus, keyboard layout, Windows scaling and controller state affect the real usage context. FullTilt does not restore foreground focus after actions or recording.

Users configure Keybindings, Movement, Pie Menus and Settings, and keep whole-app profiles beside the portable executable. Keybindings and pie edits require Save changes; Movement applies and saves immediately. Pause and Release/cancel provide session control. Closing the settings window hides it to the tray; File → Exit FullTilt and tray Exit use the same clean shutdown path.
